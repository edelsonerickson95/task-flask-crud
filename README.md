# 🚀 Task Manager API - Python & Flask

Este projeto é uma API de gerenciamento de tarefas (To-Do List) desenvolvida durante o curso **"Python: Desenvolva aplicações completas utilizando Python e Flask"** da **Rocketseat**. O objetivo principal foi aplicar conceitos de rotas, manipulação de dados e arquitetura REST.

##  Funcionalidades

A API permite realizar todas as operações de um CRUD:
- **Criar** uma nova tarefa.
- **Listar** todas as tarefas cadastradas.
- **Visualizar** detalhes de uma tarefa específica por ID.
- **Atualizar** informações de uma tarefa (título, descrição, status).
- **Remover** uma tarefa da lista.

##  Tecnologias Utilizadas

- **Python 3.12+**
- **Flask**: Micro-framework para desenvolvimento web.
- **Postman**: Ferramenta para testes de requisições HTTP.
- **PyCharm**: IDE utilizada para o desenvolvimento.

## Como executar o projeto

### 1. Clonar o repositório
```bash
git clone https://github.com/edelsonerickson95/task-flask-crud.git
cd task-flask-crud
``` 
### 2. Configurar o ambiente virtual (VENV)
```bash 
# Criar o ambiente
python3 -m venv venv

# Ativar o ambiente
source venv/bin/activate
```



### 3. Instalar as dependências
``` Bash
pip install -r requirements.txt
```
### 4. Rodar a aplicação
```bash
python3 app.py 
```
